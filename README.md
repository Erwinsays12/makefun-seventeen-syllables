A deterministic program that writes one original haiku about debugging
(three lines, 5-7-5 syllables) to `/output/entry.txt`.

## The haiku

> Cursor blinks at three
> the last log line points nowhere
> the typo was mine

## Run

```sh
python3 main.py
```
